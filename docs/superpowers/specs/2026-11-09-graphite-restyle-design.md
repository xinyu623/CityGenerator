# 前端石墨灰改版 · 设计

日期：2026-11-09

## 意图与原因

网页现在的暖米卡片 + 铁锈红强调，和数据集预览海报（Warm Graphite）不是一套调子。
这份网页的主要"产物"就是效果图——README 里的 `docs/images/frontend.png`、`preview.png`
和 `models/city_cores/previews/*` 是同一批人看的同一件事。改版让两边共用一套语言：

- 纸底 `#F2EFE9`，石墨灰阶，细线、留白、小号大写标签；
- 全场只留一处暖色（主按钮 + 进度条），其余让灰阶承担层级；
- 3D 预览按高度上石墨渐变，纸底、软接地影，网页里截的图可以当效果图直接用。

## 目标

1. 外壳（顶栏、侧栏、面板、表单、按钮、结果卡、页脚、弹窗）统一到石墨灰 token。
2. 主操作仍是全场唯一暖色，面积小到"指示"而不是"装饰"。
3. 3D 预览的调子与 `overview_3d.png` 一致：纸底、建筑按高度由浅灰渐到近黑。
4. 颜色收敛成一组 `:root` token，后续换色只改一处。

## 非目标

- 不改功能、不改 DOM 结构、不改栅格布局；不做暗色模式。
- 不重写生成/几何管线，不动 VIEWER 的交互（旋转、线框、重置）。
- 不新增依赖，不引入 web font（沿用现有系统字体栈）。

## 反目标

- 出现第二种强调色（蓝、绿、紫）。
- 地图被压成黑白，选区、路网、水系读不出来。
- 3D 楼体和底片糊成一片，看不出体量。

## 约束

- 地图仍是 OSM 栅格瓦片，只允许 CSS 调色，不换 tile 源。
- 3D 的色值必须与海报同源：纸底 `#F2EFE9`，渐变起 `#DCD6CC`、止 `#241F1B`。
- 字体不改，只调字重与字距。

## 备选与取舍

| 方案 | 说明 | 结论 |
|---|---|---|
| A 只换外壳，地图彩色 | 改动最小；但彩色底图与单色外壳仍有张力 | **采用**，附降饱和 `saturate(.55)` |
| B 全页单色，地图也灰 | 最像海报；但选区和路网辨识度下降 | 未采用；CSS 留 `--map-filter`，一行可切 |
| C 保留大面积铁锈红 | 视觉延续性强；但不是"白灰" | 未采用，暖色只留主按钮与进度条 |

用户选定：外壳石墨灰 + 小面积暖色 + 3D 换成石墨色。

## 已定的做法

1. **外壳灰阶**：背景 `#EDEAE3`、面板 `#F7F5F0`、正文 `#231F1B`、次级 `#3C3733`、
   弱化 `#756E66`、细线 `#DCD7CC` / `#C3BDB1`。面板圆角 10px、控件 8px，边框一律 1px。
2. **单一暖色**：`--accent: #A7472C`，只用于主按钮填充与进度条；step 标签、badge、
   链接、页脚点、3D 标签点全部转灰。
3. **地图**：保持彩色，`filter: saturate(.55) contrast(.96) brightness(1.03)`；
   选框描边与填充改为石墨灰 + 半透明纸色。
4. **3D 预览**：背景与台座同为纸底 `#F2EFE9`（台座融进背景，只留柔和接地影）；
   建筑/地面/墙面用顶点色按世界 Y 做 Warm Graphite 渐变；灯光改中性白，曝光上调。
5. **品牌块**：`CG` 由铁锈红渐变改为石墨渐变（深灰块 + 纸色字）。

## 留给实现者的

- 灰阶的具体微调、圆角与字重的最终数值；
- 高度渐变的分段位置与色调映射曝光；
- 改前/改后截图对比。
